# Uncle Turkey

A fall-festive gag website celebrating the persona Uncle Turkey, with mini games, origin lore, and light shopping links.

## Language

**Uncle Turkey**:
The main character and site namesake — Daniel as a fall-festive turkey (also called **Daniel Turkey**). The brand of the site is this character.
_Avoid_: The turkey, mascot (unless referring to a generic decorative turkey); using Uncle Turkey for guest characters

**Daniel Turkey**:
The same person as Uncle Turkey; preferred when stressing the real-world first name next to other Guest Turkeys.
_Avoid_: A separate character from Uncle Turkey

**Guest Turkey**:
A cameo turkey character built like Uncle Turkey but for another person, named **{Name} Turkey** (for example Steph Turkey, Brandon Turkey).
_Avoid_: Uncle Turkey, NPC, skin

**Mini Game**:
A playable gag game hosted on the site (for example a Duck Hunt–style shooter).
_Avoid_: App, level, experience

**Turkey Hunt**:
The first Mini Game — a Duck Hunt–style gag shooter. Repo id: `turkey-hunt`.
_Avoid_: Duck Hunt (the real game), sample-game

**Games Hub**:
The site section that lists and links to available Mini Games.
_Avoid_: Arcade, game library, lobby

**High Score**:
A recorded best result for a Mini Game, kept so players can compare runs. Submitted with an optional Display Name; there are no player accounts.
_Avoid_: Scoreboard entry (unless distinguishing a ranked list from the raw best value), leaderboard (the ranked display of High Scores)

**Display Name**:
An optional nickname attached to a High Score submission. Not a login identity.
_Avoid_: Username, account, player profile

**Origin Story**:
The narrative of how Uncle Turkey came to be, told as site content rather than as a game.
_Avoid_: Lore dump, backstory page (prefer Origin Story as the canonical name)

**Turkey Link**:
A curated outbound link (for example a turkey costume or store item) presented as site content, not as inventory the site sells itself.
_Avoid_: Product, SKU, listing (unless a real catalog appears later)

**Turkey Asset**:
A finished gag image of Uncle Turkey or a Guest Turkey that ships with the site or a Mini Game: stylized cartoon turkey body with a recognizable but illustrated face (not a photoreal paste). Not a raw photograph.
_Avoid_: Source photo, headshot, likeness plate (those stay private and out of the public repo); Uncle Turkey Asset (prefer Turkey Asset as the general term)

**Pose Pack**:
The small canonical set of still Turkey Assets per character used before full sprite sheets: typically portrait, idle, flap, and hit.
_Avoid_: Sprite sheet (a later packed atlas), animation reel

**Source Likeness**:
A private real-world photo or crop of the friend’s face used only as a generation reference. Never committed to the public repository.
_Avoid_: Uncle Turkey Asset, avatar, profile pic

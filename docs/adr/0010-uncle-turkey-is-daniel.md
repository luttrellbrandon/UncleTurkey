# Uncle Turkey is Daniel; guests are named {Name} Turkey

The site needs a clear hero character plus optional guest cameos (Steph, Brandon, and others). We considered treating everyone as peer “Turkey” characters under a brand-only Uncle Turkey, compositing shared bodies with private face plates, and naming Uncle Turkey as Daniel alone with guests as “{Name} Turkey.” We chose Uncle Turkey = Daniel Turkey as the main character, with Guest Turkeys named Steph Turkey, Brandon Turkey, and so on, so folders, prompts, and copy have an unambiguous hero and a simple naming rule for cameos.

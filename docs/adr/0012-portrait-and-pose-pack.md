# Start with portraits and a small pose pack per character

Turkey Assets must cover site chrome and early Mini Games for Uncle Turkey and Guest Turkeys. We considered Phaser sprite sheets from day one, frame-sequence folders only, and a still portrait plus a small pose pack (`idle`, `flap`, `hit`). We chose portraits and a small pose pack first so GPT prompts stay consistent across the cast and we can add sheets later without blocking the site.

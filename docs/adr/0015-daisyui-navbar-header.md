# Site chrome uses a DaisyUI navbar

The site needs a clear navigation header under the locked autumn theme. We considered a quieter chrome nav with a Home-only hero brand, a minimal non-Daisy header, and a DaisyUI `navbar` with Uncle Turkey as brand plus section links (including a mobile menu). We chose the DaisyUI `navbar` so navigation matches Daisy components elsewhere and stays usable on mobile without a custom nav system.

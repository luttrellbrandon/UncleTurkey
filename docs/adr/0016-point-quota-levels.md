# Turkey Hunt levels clear on a point quota

Turkey Hunt is a crosshair shooter: the mouse is the gun, and you click flying Hunt Targets. We considered clearing a Level by hit count, shipping one endless score round first, and clearing on a Point Quota before time runs out or too many Fly-offs. We chose the Point Quota because Brandon Turkey is worth −100, so a penalty bird has to be able to cost you the Level, while a limited number of Shots per bird keeps the Duck Hunt feel.

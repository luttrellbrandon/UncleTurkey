# Rivalries are scenery and one-liners, not new controls

Turkey Hunt should nod at the ping pong, fishing, and racquetball contests. We considered a different movement model per rivalry, joke cards with one shared sky, and the same shooter on every Level with a rivalry backdrop and a short line. We chose scenery and one-liners so the first game is one crosshair loop, and the contests still show up on the playfield.
